LisAI Interpreter

Real-time recognition of Italian Sign Language (LIS), from webcam frames to Italian text. Built on a custom dataset, because for LIS, unlike ASL, large public corpora barely exist.

LIS is a full language with its own grammar, not signed Italian. This project tackles the perception layer: a webcam stream goes through MediaPipe Holistic, which extracts 543 landmarks per frame (468 face mesh, 33 pose, 42 hand points), normalized relative to the shoulder midpoint so the model is invariant to distance and framing.

The system is two-tier. Tier one, static fingerspelling: a compact MLP / 1D-CNN over 63-dimensional hand vectors classifies the 26 letters at 87.3% accuracy in real time. Tier two, word-level recognition over landmark sequences, was explored as a research track with sequence models.

How it works

  1. Data expansion. A custom FFmpeg augmentation engine multiplies the dataset: horizontal flips for handedness swap, ±15° rotation and scale jitter, 0.8x to 1.2x speed changes, Gaussian blur and brightness shifts.
  2. Landmark extraction. MediaPipe Holistic produces 543 keypoints per frame, spatially normalized to the shoulder midpoint.
  3. Classification. Static tier: MLP / 1D-CNN on 63-dim hand vectors (3 Dense layers, ReLU, Dropout 0.3). Dynamic tier: sequence models over (T, 1662) feature matrices with forward padding and masking for variable-length signs (20 to 180 frames).
  4. Linguistic refinement. A Beam Search context engine combines model confidence with a word-frequency dictionary, then a local LLM (Gemma via LM Studio) turns LIS glosses into grammatical Italian.

From gloss to Italian

gloss → IO MANGIARE MELA
llm → "Sto mangiando una mela"
gloss → DOMANI IO ANDARE MARE
llm → "Domani vado al mare"

Research track

Word-level recognition is genuinely harder than fingerspelling: signs are dynamic, variable-length, and disambiguated by context. The research track compared Bi-LSTM (bidirectional layers let the model see how a sign ends before classifying how it began), Transformer encoders (parallel attention across the full gesture sequence) and GRU as a lighter alternative, trained in mixed precision (FP16) with checkpoint management.

Honest status. The static tier (letters) is the working, measured result: 87.3% on 26 classes in real time. The dynamic tier (words) is a research direction with a working training pipeline, reported here as exploration, not as a finished product.
